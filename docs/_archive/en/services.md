# Available services

Overview of the SCS Sammlungen platform services. Domains below use the production `scs.sammlungen.io` pattern; your instance may use a different subdomain (for example `dev-scs`).

| Service | What it is for | Typical URL |
|---------|----------------|-------------|
| **SCS Manager** | Collection and project management | `https://manager.scs.sammlungen.io` |
| **File Storage (Drive)** | Nextcloud file sharing and collaboration | `https://drive.scs.sammlungen.io` |
| **JupyterHub** | Interactive notebooks and computing | `https://code.scs.sammlungen.io` |
| **Authentication** | Keycloak sign-in for all services | `https://auth.scs.sammlungen.io` |
| **Open GDB** | Knowledge graph / triplestore | `https://ts.scs.sammlungen.io` |
| **Project Website** | Public project information | `https://project-website.scs.sammlungen.io` |

Related: [SCS Drive guide](scs-drive.md).
