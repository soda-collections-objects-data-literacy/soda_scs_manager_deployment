# Verfügbare Dienste

Überblick über die Dienste der SCS-Sammlungen-Plattform. Die Domains unten folgen dem Produktionsmuster `scs.sammlungen.io`; deine Instanz kann eine andere Subdomain nutzen (z. B. `dev-scs`).

| Dienst | Wofür | Typische URL |
|--------|--------|--------------|
| **SCS Manager** | Sammlungs- und Projektverwaltung | `https://manager.scs.sammlungen.io` |
| **Dateispeicher (Drive)** | Nextcloud: Dateien teilen und gemeinsam bearbeiten | `https://drive.scs.sammlungen.io` |
| **JupyterHub** | Interaktive Notebooks und Rechnen | `https://code.scs.sammlungen.io` |
| **Authentifizierung** | Keycloak-Login für alle Dienste | `https://auth.scs.sammlungen.io` |
| **Open GDB** | Knowledge Graph / Triplestore | `https://ts.scs.sammlungen.io` |
| **Projekt-Website** | Öffentliche Projektinformationen | `https://project-website.scs.sammlungen.io` |

Siehe auch: [SCS Drive](scs-drive.md).
